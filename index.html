SimpleIntegration
JohnDoe.cs
public class JohnDoe : NPC
{
    protected override string FirstName => "John";
    protected override string LastName => "Doe";
    private bool _hasIntroduced = false;
    private Log _logger = new Log("JohnDoe");

    public JohnDoe() : base("johndoe", "John", "Doe")
    {
        TimeManager.OnDayPass += OnDayPass;
        _logger.Msg("NPC Created");
    }

    private void OnDayPass()
    {
        if (!_hasIntroduced)
        {
            SendTextMessage("Hello, I'm John! Nice to meet you.");
            _hasIntroduced = true;
        }
    }
}

Key Features

S1API provides a robust cross-compatibility layer between Mono and Il2Cpp with powerful capabilities

Simplified API

Use a clean, consistent API that abstracts away the differences between backend implementations.

Cross-Platform Compatibility

Seamlessly run your code on both Mono and Il2Cpp backends without any modifications.

Data Persistence

Easy-to-use abstraction for save/load of class data regardless of backend implementation.

Game Element Access

Easily access and manipulate game objects, components, and resources regardless of the backend.
